## Introduction

What is this package? What does it? This package includes only two
Turbo Pascal sources (For TP 6.0 and above!) showing how to control
the fm- and digital-sounds of Sound Blaster soundcard (or
compatible). I wrote these pieces of source just because I wanted
to learn programming of SB. After that I decided to wrote
an article of Sound Blaster programming and I sent these sources
with it as a example programs. Because I'm not sure about releasing
of my article, I created this "little" tutorial package. Be free
to learn Sound Blaster programming with this tutorial!

[EXAMPLE1.PAS](EXAMPLE1.PAS) shows how to use fm-sounds of SB/AdLib   
[EXAMPLE2.PAS](EXAMPLE2.PAS) shows how to use digital sounds of SB
